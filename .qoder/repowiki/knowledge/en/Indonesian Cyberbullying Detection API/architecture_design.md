- **Entry Point**: `main.py` initializes the FastAPI application, configures middleware (CORS, security headers, Prometheus metrics), and manages the lifespan event for model initialization and database connections.
- **Routing Layer**: Organized in `routes/`, with `predict.py` handling public prediction endpoints, `admin.py` aggregating administrative routers (auth, scraper, HITL, training, settings), and `deps.py` providing shared dependencies like JWT authentication and rate limiting.
- **Classification Core**: The `classifier/` package implements a hybrid inference engine. `predictor.py` orchestrates a three-tier fallback strategy: Tier 1 (Lexicon/ML), Tier 2 (Transformer Ensemble), and Tier 3 (Cloud LLM with RAG). State management and model loading are centralized in `predictor_base.py`.
- **Data & Infrastructure**: `classifier/database.py` and `db_config.py` manage connections to PostgreSQL (with pgvector for embeddings), Redis (caching/pub-sub), and SQLite (fallback cache), featuring automatic schema migration and Fernet encryption for stored text.
- **External Integrations**: `scraper/` contains Playwright-based scrapers for TikTok and X/Twitter. `tasks.py` defines Celery workers for background model retraining and scraping jobs.
- **Configuration**: Settings are managed via `settings_store.py` (Redis/JSON) and environment variables, with dynamic ensemble weight recalibration supported in `routes/settings.py`.
